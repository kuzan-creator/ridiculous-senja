A one-sentence startup pitch for the make.fun bounty "Ridiculous at First Glance, Real by the Second": it proposes hiring reformed burglars to test a home's defences the way a real intruder would, then reporting every weakness they found. Absurd on the first read, obvious on the second — homeowners already pay good money for security gear without ever learning whether any of it would actually hold up.

## Run it

```sh
node main.ts
```

Running it writes the pitch as a single sentence to `entry.txt` inside the output directory (taken from `MAKEFUN_OUTPUT_DIR`, or `/output` by default).
